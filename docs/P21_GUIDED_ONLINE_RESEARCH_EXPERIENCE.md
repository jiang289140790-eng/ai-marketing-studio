# P21 智能引导研究体验

## 用户结果

`#/research` 默认进入“引导视图”，只展示当前最值得处理的一步，降低原完整工作台同时呈现大量面板造成的认知负担。用户仍可切换到“完整视图”，复核全部项目档案、证据、分析、知识卡、Brief、交接包和世系审计。

## 确定性引导规则

引导顺序固定为：研究项目 → 证据 → 分析 → 知识卡 → Brief → 人工审核 → 交接包 → 世系审计。

- 默认选择第一项未完成步骤，不调用模型，也不基于概率推断。
- 点击顶部步骤可以查看对应真实生产面板；人工审核与 Brief 共用同一生产面板。
- “回到建议步骤”会清除浏览偏移，重新显示确定性建议步骤。
- 已归档项目只读并直接引导到世系审计。
- 显示模式仅保存在浏览器本地，不进入项目数据、数据库合同或导出文件。

## 保持不变的边界

- P19/P20 的在线保存、重新读取、导入重放、冲突处理和来源链保持不变。
- 四项执行标志继续严格为 `false`。
- P21 不增加采集、模型、生成、路由、发布、数据库迁移、RLS、GRANT、Auth 或 Edge Function 能力。
- 完整视图保留原来的审计与人工操作入口，不隐藏已有功能。

## 验收

- 聚焦单元测试验证每个完成阶段的下一步、人工查看覆盖、归档与失败关闭。
- 真实浏览器回归通过生产进度控件重新打开项目面板，并复验 P20 在线保存和冲突提示。
- 完整前端测试（既有数据库回放环境项除外）、类型检查、lint、构建和迁移静态检查通过。
